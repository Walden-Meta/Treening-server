# Treening · 操作手册

> **这是什么**：Treening（Tree + Learning）—— 一棵会生长的知识树。已上线真实域名 **https://treening.cc**，运行在独立容器里。
>
> **当前形态**：**账号制网站**。首次访问创建管理员账号，管理员可添加亲友账号；普通用户登录后使用自己的知识树。
>
> **一句话**：把"一个真正困扰你的问题"放进来，让它长成一棵有路径的知识树。

# 第一篇 · 按模块功能讲解

## 模块 1：账号体系（登录 / 注册 / 忘记密码）

- **是什么**：站点现在是**账号制**。没有账号的人会看到登录页；首次访问（服务器还没有任何账号时）会引导你**创建管理员账号**。
- **怎么用**：
  - **首次启动**：打开站点 → 进入"创建管理员账号"页 → 填用户名 + 密码（8-64 位）→ 创建并进入；
  - **普通用户**：由管理员在管理面板手动创建（或开放注册开启后自助注册），然后用账号密码登录；
  - **忘记密码**：登录页点「忘记密码」→ 输入绑定邮箱 → 收到重置链接（需管理员在管理面板配置过邮件服务）。
  - **新账号开箱**：注册或由管理员创建后，学习空间自动预置第一棵**「你是谁」样例树**（标题「你好，我是春宁」）——完整演示三出口与树的生长，可先体验、可随意折腾、也可删掉换自己的树。
- **说明**：密码以 PBKDF2 盐化存储；连续 5 次登录失败会临时锁定；同一 IP 注册有频率限制。退出登录点右上角「登出」。

## 模块 2：首次配置（模型服务）

- **是什么**：管理员首次登录后，进入配置页填写模型服务——**API Key、接口地址（默认 DeepSeek）、模型**。
- **怎么用**：
  1. 打开配置页，填 **API Key**、**接口地址**、**模型**；
  2. 点「测试连接」验证；
  3. 点「保存并开始」回到学习空间；
  4. 之后「⚙ 配置」可随时调整。
- **说明**：Key 只保存在服务器本地 `data/settings.json`，页面只显示掩码，永不明文回传。普通用户看不到这一栏（由管理员统一配置）。

## 模块 3：个性化配置页（普通用户也有）

- **是什么**：配置页里，除模型服务外的所有栏目都是**按人独立**的个性化设置。
- **六项设置**：

  | 栏目 | 作用 |
  |------|------|
  | **自定义人设** | 作用于所有对话，不按主题区分。**春宁是底座人设**：留空 = 默认「春宁」；填入文字 = 用它覆盖默认；清空保存 = 恢复默认。此栏只作覆盖/重置，不参与初始设置 |
  | **分支节点命名** | 三个出口的显示名（默认 验收 / 追问 / 其他），可自定义 |
  | **画布布局** | 全局排版参数：问答间距、衔接间距、卡片默认宽高 |
  | **拆解模块** | 每个回答附带的"镜片拆解"开关，不想要的模块可关掉 |
  | **绑定邮箱** | 用于忘记密码找回（可选） |
  | **修改密码** | 验证当前密码后改新密码 |

- **画布布局四个参数**：
  - **一组问答之间的线长**（默认 44）：问题卡与回答卡之间的纵向间距；
  - **不同问答之间衔接的线长**（默认 82）：上一回答到下一问题的间距；
  - **卡片默认宽 / 高**（默认 300 × 180）：自动排版时新卡片的尺寸。
  - **注意**：修改布局参数会重置所有节点的手动摆放位置，整棵树按新参数重排。

## 模块 4：管理员面板（只有管理员可见）

- **是什么**：右上角「管理」进入，管理用户与系统设置。普通用户看不到入口。
- **功能**：
  - **开放注册开关**：开启后登录页出现注册入口，访客可自助创建普通用户账号；
  - **邮件服务**：配置 SMTP（QQ 邮箱需填**授权码**而非登录密码），支持"发送测试邮件"验证；
  - **用户管理**：表格列出每位用户 —— 角色 / 状态 / 邮箱 / 主题数 / 节点数 / **配额（今日用量）** / 最近活跃 / 最近登录；
  - **每用户操作**：改密、设邮箱、**配配额**、设为/降为管理员、禁用/启用、删除；
  - **创建用户**：底部输入用户名 + 初始密码 + 邮箱 + 角色，一键创建。
- **配额管理**：点某行「配额」按钮，输入 **留空 = 全局默认、0 = 不限额、数字 = 每日 N 次**。管理员恒不限额。

## 模块 5：学习会话（一棵树 = 一个主题）

- **是什么**：每次学习是一个主题，一棵知识树。可建多棵，历史全部保留，按时间自动分组。
- **怎么用**：
  - **开始**：在输入框提出第一个问题，第一次提问正式创建主题（新账号除外——已预置样例树）；
  - **新账号预置**：新账号自动带一棵**「你是谁」样例树**（标题「你好，我是春宁」），把三出口与树的生长完整演示一遍——先玩熟它，再删掉种自己的树；
  - **新主题**：右上角「新主题」；
  - **切换**：左栏「学习轨迹」点任意一条；
  - **历史分组**：自动分「今天 / 最近 7 天 / 更早」；
  - **当前主题**：顶部显示主题名。
- **每日配额**：普通用户每日有提问次数上限（默认 10 次，管理员可在管理面板按人调整），顶部会显示剩余次数，用完提示明日再来。

## 模块 6：三出口分支（核心规则）

- **是什么**：每个回答固定长出**三个出口**：**验收**（写下理解让系统检查）、**追问**（钻细节）、**＋ 其他**（自定义支线）。
- **怎么用**：
  - 点回答卡片上的「分支」抽屉，选「验收 / 追问 / ＋其他」；
  - 或点输入框上方的「验收理解 / 追问细节 / ＋其他分支」。
- **规则**：
  - 每个回答最多 3 个子分支，同一槽位不重复；
  - 只能从**回答节点**继续，不能从提问节点挂分支。
- **上手**：新账号的第一棵样例树就把三个出口各自长了一枝（验收 / 追问 / 其他各一条），照着点一遍即懂。

## 模块 7：知识树画布（核心工作区）

- **是什么**：整棵树的图形化空间，节点按层自动排布，彩色连线区分分支类型。**画布是页面的主角。**
- **画布操作**：

  | 位置 | 控件 | 作用 |
  |------|------|------|
  | **左上角** | 完整树 / 邻近分支 / 当前路径 | 切换视图模式 |
  | **右上角** | OVERVIEW 缩略图 | 俯瞰全树，点击跳转 |
  | **右上角（缩略图下）** | 全部隐藏 / 全部显示 | 一键摘要化整棵树 |
  | **右下角** | 撤销 ↶ / 缩放 −＋ / 回到全图 | 画布导航与操作 |

- **交互**：
  - **缩放**：滚轮悬停画布即缩放；
  - **平移**：空白处直接拖动；
  - **拖动节点**：按住卡片拖，位置自动保存；**画布四向无墙**——左、上方向同样可无限拖出（负坐标区域照常渲染），不再有边界钳制；
  - **调整大小**：拖卡片右下角小尖，**左上角固定、只拉右下角**；
  - **框选**：按住 **Ctrl/⌘ + 拖拽** 圈选多个节点，整体发光提示；
  - **撤销**：**Ctrl+Z** 或右下角「↶ 撤销」。

## 模块 8：三种视图（完整树 / 邻近分支 / 当前路径）

- **完整树**：看全部节点（默认，不压暗）；
- **邻近分支**：只看当前节点所在路径 + 附近分支，其余淡化；
- **当前路径**：只保留从根到当前节点的这条链。
- **细节**：切换视图不重排布局，保留缩放和平移。

## 模块 9：奏折式折叠（收起整棵子树）

- **是什么**：把任意回答节点下的整棵子树折叠成一张"扑克牌堆"贴在父节点上。
- **怎么用**：点卡片「收起」叠成牌堆；点「展开」滑回原位。
- **细节**：折叠只叠牌、不重排；折叠状态按主题分别记忆。

## 模块 10：节点管理（收起 / 隐藏 / 详情 / 删除）

- 每张卡片一组操作：
  - **收起 / 展开**：折叠整棵子树（见模块 9）；
  - **隐藏**：内容收起，只留一句语义摘要；点「显示」还原；
  - **详情**（右下角）：打开全文阅读栏；
  - **分支**（仅回答卡）：展开三出口；
  - **删除**（仅提问卡）：删除该问题及整棵子树，二次确认。

## 模块 11：阅读栏（点「详情」打开）

- 右侧滑出面板，显示节点完整正文 + 位置上下文：
  - 当前路径（起点 → 追问 → 验收）、父节点、后代数；
  - 操作：「收起后代」「隐藏内容」「导出路径」「定位节点」；
  - 点空白处或 `Esc` 关闭。
- **说明**：单击卡片只做选中，**查看全文统一走「详情」**。

## 模块 12：显示控制（全部隐藏 / 全部显示）

- 画布右上角（overview 下方）的一键开关，把整棵树压成"摘要图"。
- 「全部隐藏」自动为缺摘要的节点生成语义摘要；「全部显示」一键还原。

## 模块 13：输入框按需出现

- 底部的提问输入框**不常驻**，只在需要时出现：
  - 空树（0 节点）时始终显示；
  - 点回答卡的「分支」抽屉、或快捷入口（验收 / 追问 / ＋其他 / 新开问题）时出现；
  - 提问后回答长出时收起；未发问时点空白收起。
- **为什么**：先选准"从哪个回答的哪个出口继续"，再输入问题。

## 模块 14：导出（把树带走）

- header 右侧导出控件，三种范围 × 三种格式：
  - **范围**：完整知识树 / 当前路径 / 当前节点及后代；
  - **格式**：Markdown（含 Mermaid 图）/ TXT / DOCX；
  - 点「下载」即得文件。

## 模块 15：深夜模式 + 配置

- **深夜 / 日间**：header 右侧一键切换，跟随系统偏好，持久化到浏览器。
- **登录页也有**：登录 / 注册页标题旁同样有切换开关。
- **⚙ 配置**：回到配置页，调整模型 / 人设 / 命名 / 布局 / 拆解等。

## 附带：快捷键

| 快捷键 | 作用 |
|--------|------|
| Enter | 发送输入框内容 |
| Shift + Enter | 输入框换行 |
| Ctrl + Z | 撤销上一步画布操作 |
| Ctrl/⌘ + 拖拽 | 框选多个节点 |
| 滚轮（悬停画布） | 缩放画布 |
| Esc | 关闭阅读栏 / 面板 |

# 第二篇 · 按整体布局讲解

## 整体结构

整个站点现在由四个页面构成：**登录页 → 学习空间 → 配置页 → 管理员面板**。你从登录页进入后，日常绝大多数时间都在**学习空间**；配置与管理按需前往。

## 1. 登录页（/login）

- **进入**：浏览器打开站点即到。
- **区块**：标题「登录学习空间」+ 标语「把一个问题，长成一棵知识树」、主题切换开关、用户名输入、密码输入、登录按钮；底部是「查看操作手册」入口。
- **操作手册**：任意访客可点「查看操作手册」下载 PDF（/manual，公开端点，无需登录）。
- **忘记密码**：点「忘记密码」→ 输入绑定邮箱 → 收到重置链接；未配置邮件服务时此入口不可用（管理员需先在管理面板配置 SMTP）。
- **注册**：管理员开启「开放注册」后出现注册入口，新访客可自助创建普通用户账号；注册页注明"人设与知识树各自独立"，每个新账号开箱自带一棵「你是谁」样例树。
- **细节**：同一 IP 注册有限流；连续 5 次密码错误会锁定该账号 10 分钟；登录成功后自动回到学习空间。

## 2. 学习空间（/，主工作区）

按视线从上到下、从左到右：

- **顶部 Header**：
  - 左：Logo + 站点名 + 当前主题名；
  - 中：空位；
  - 右：主题状态、配额剩余（普通用户）、导出、深夜模式切换、⚙ 配置、管理（仅管理员）、用户名、登出。
- **左侧学习轨迹**：所有主题的列表，按「今天 / 最近 7 天 / 更早」分组；点任意一条切换当前主题。新账号首次进入就有一棵预置的「你是谁」样例树躺在这里，先玩熟它。
- **中央知识树画布**：主体工作区，节点按层排布、彩色连线；左上角三种视图、右上角 OVERVIEW 缩略图 + 全部隐藏/显示、右下角撤销/缩放/回全图。
- **底部输入区**：按需出现的提问输入框 + 快捷分支入口（验收 / 追问 / ＋其他 / 新开问题）。

## 3. 配置页（/setup）

- **入口**：Header 右上「⚙ 配置」。
- **布局**：与管理员面板一致的单列卡片式 UI，从上到下共 8 张卡：
  1. **注册信息**（仅未注册时出现）：创建管理员账号 —— 用户名 + 密码 + 确认密码；
  2. **模型服务**（仅管理员）：API Key / 接口地址 / 模型 / 测试连接 / 保存；
  3. **自定义人设**（普通用户与管理员都有）：作用于所有对话，不按主题区分。**春宁是底座人设**——留空即用默认「春宁」；填入文字用它覆盖默认；清空保存恢复默认。此栏只作覆盖/重置，不参与初始设置；
  4. **分支节点命名**：三个出口显示名；
  5. **画布布局**：问答间距 / 衔接间距 / 卡片默认宽高；
  6. **拆解模块**：每个回答附带模块的开关；
  7. **绑定邮箱**：用于忘记密码找回（可选）；
  8. **修改密码**：验证当前密码后设置新密码。
- 每张卡保存后独立生效；右上「返回学习空间」随时回到主工作区。

## 4. 管理员面板（/admin，仅管理员可见）

- **入口**：Header 右上「管理」（普通用户看不到）。
- **布局**：单列卡片式，从上到下 3 张卡：
  1. **开放注册**：一键开关 + 当前状态；
  2. **邮件服务**：SMTP 配置（主机 / 端口 / SSL / 账号 / 授权码 / 发件人）+ 发送测试邮件 + 保存；
  3. **用户管理**：完整用户表格 + 底部创建用户。
- **用户表格列**：用户名（自己标注"（我）"）、角色徽章、状态（在线/离线/已禁用）、邮箱、主题数、节点数、**配额（今日用量）**、最近活跃、最近登录、操作按钮。
- **每行操作**：改密 / 邮箱 / **配额** / 设为管理员或降为普通 / 禁用或启用 / 删除。
- 列表每 30 秒自动刷新，在线状态保持新鲜。

## 视觉与导航的一致性

四个页面的所有控件都遵循同一套视觉语言：

- **卡片**：统一圆角描边卡片，分区清晰；
- **主题**：每页右上角都有深夜/日间切换，全局一致且记忆偏好；
- **配色**：日间暖底 + 夜间深底，强调色（蓝）贯穿按钮、徽章、连线；
- **返回**：配置页与管理页都有「返回学习空间」，不打断当前学习。

# 第三篇 · 按设计思路讲解

## 设计总纲

Treening 的核心理念是：**学习不是一条线，而是一棵树；树的每一根枝都可以被追问、被验收、被自定义地延伸。** 所有设计决策都围绕这一个理念展开。

## 一、为什么要"树"而不是"聊天记录"

- **可回顾**：聊天记录是线性的，翻找历史很痛苦；树形结构让"上次学到哪、沿哪条枝展开"一目了然。
- **可裁剪**：任何一条分支都可以收起、隐藏、删除，而不影响其余部分。
- **可追踪**：三种视图（完整树 / 邻近分支 / 当前路径）从"全局"到"局部"到"单链"自由切换，理解不迷路。

## 二、画布优先：为什么画布是主角

- **空间感**：先看到全局结构再深入细节，比逐条滚动更符合人脑的地图式记忆。
- **非破坏**：拖动、缩放、框选都只改变"看的方式"和"摆放位置"，不改变内容；撤销随时可回退。
- **焦点控制**：单击只选中、双击/详情才展开全文，避免画布被文字淹没。

## 三、三出口分支：强制"继续"的规则

每个回答固定长出 **验收 / 追问 / ＋其他** 三个出口，并限制每卡最多 3 个子分支：

- **验收**是"输出"，迫你写下理解让系统检查 —— 费曼学习法的具体化；
- **追问**是"深入"，顺着当前枝钻细节；
- **＋其他**是"自由"，不预设路径地开新支。
- 限制分支数量的设计意图：**先消化再扩展**，防止"为问而问"地无限分叉。

## 四、配置页全面对齐管理模块的 UI

- 同一套卡片、同一套描边、同一个顶部结构，管理员和普通用户看到的界面语言完全一致，降低学习成本；
- 全局设置（模型服务）与个人设置（人设 / 命名 / 布局 / 拆解）分卡呈现、权限分离 —— 管理员改模型，用户改习惯，互不干扰；
- 每次保存即时生效、独立反馈，不依赖"整体提交"。

## 五、安全策略（v0.2.0 新增）

| 层 | 措施 | 作用 |
|----|------|------|
| 账号 | PBKDF2 盐化密码存储 | 数据库泄露也不泄露明文密码 |
| 账号 | 连续 5 次失败锁定 + 每 IP 注册限流 | 防暴力破解、防批量注册 |
| 会话 | 随机持久化密钥 + HttpOnly + SameSite=Lax Cookie | 登录态不可伪造、防 XSS 窃取 |
| 配额 | 普通用户每日默认 10 次提问，管理员不限，可按人覆盖 | 控制 API 成本、防止滥用 |
| 传输 | HSTS + 强制 HTTPS（nginx 层） | 防中间人窃听 |
| 应用 | 安全响应头：nosniff / X-Frame-Options / Referrer-Policy / Permissions-Policy / CSP | 防 MIME 嗅探、点击劫持、信息泄漏 |
| 密钥 | API Key 只存服务器本地，页面只回显掩码 | 不在浏览器暴露模型密钥 |

## 六、配额的设计

- **默认值**：普通用户每人每日 10 次提问，够日常学习也控制成本；
- **管理员**：恒不限额，避免被日常调试误伤；
- **按人覆盖**：管理员面板里每位用户可单独设为"留空=默认 / 0=不限 / N=每日 N 次"；
- **用户体验**：顶部实时显示剩余次数，用完温和提示，不打断已生成的内容。

## 七、深夜模式的取舍

- 跟随系统偏好 + 手动切换，持久化到浏览器；
- 深色下选中态用白色高亮与日间蓝色区分，保证低光环境可辨识；
- 全局统一，四个页面一致。

## 八、底座人设：春宁 + 开箱样例树

- **春宁是底座，不是"通用风格"**：默认人设是一份随包内置的完整角色「春宁」——有名字、有来历、有说话习惯。任何账号人设留空，得到的就是春宁，而不是一句泛泛的"你是个助教"；
- **兜底链永不落空**：用户自己的配置 → 全局人设文件 data/persona.md → 环境变量 TREENING_PERSONA → 内置春宁（default_persona.md）。任一层缺失或为空，最终都会回落到春宁；
- **人设文本框只做覆盖/重置**：不承担初次设置——填入即覆盖、清空即恢复，保证底座不被误改；
- **开箱样例树**：每个新账号自动种一棵「你是谁」样例树（标题「你好，我是春宁」），把根问题、回答、三出口、树的生长一次演示完。新用户第一眼看到的是"一棵已经长出来的树"，而不是一张空画布——理解成本大幅下降。

## 数据文件（data/ 目录）

| 文件 | 内容 | 备份 |
|------|------|------|
| tree.db | 用户、主题、节点、配额等全部业务数据 | 随数据库备份 |
| settings.json | API Key、SMTP 密码、开放注册开关等**敏感配置** | **排除在备份外**，服务器本地独有 |
| .secret | 会话签名密钥（重启后登录态不失效） | 随服务器保留 |
| persona.md | 全局人设的可编辑副本（当前即「春宁」） | 可随备份；缺失时回退内置春宁，不会无人设 |

## 常见运维操作

- **重启**：`docker compose down && docker compose up -d`（会话不失效，secret 持久化）；
- **看日志**：`docker compose logs -f app`；
- **备份数据库**：先 `docker compose exec app sqlite3 data/tree.db ".backup /tmp/b.db"` 再拷出（WAL 下切勿直接复制文件）；
- **线上改配额**：不用改环境变量 —— 管理面板 → 用户管理 → 该行「配额」即可即时生效；
- **安全加固已内建**：安全响应头、登录墙、PBKDF2、锁定、限流、配额、HSTS（nginx）均已生效，无需额外配置。
