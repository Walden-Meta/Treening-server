管理员配置了全局模型作为默认。你可以在下方「我的模型服务」中使用自己的 API Key / 地址 / 模型， 也可以管理自己的个性化设置（人设、命名、拆解、布局）。

创建管理员账号

首次启动：创建管理员账号，已有学习数据会自动并入。之后管理员可在配置页添加更多用户。

模型服务（全局）

Treening 使用你自己的 API Key（BYO-Key），支持任何 OpenAI 兼容接口。配置只保存在本机。

我的模型服务

使用你自己的 API Key（BYO-Key），支持任何 OpenAI 兼容接口，只保存在本机。
全部留空 = 跟随全局默认（管理员配置）。自定义接口地址或模型时，必须同时提供你自己的 API Key。

自定义人设（3 槽位）

在这里定义最多 3 套自定义人设，每套都包含名称、备注、人设文字。保存后它们会出现在学习空间「切换陪伴者」的列表里（备注就是选择时圆点下方的灰色小字）。空槽位不显示，可随时回来补。
系统自带 3 套可直接选择：春宁（中性陪伴）/ 理性春宁（研究搭档）/ 感性春宁（先接住情绪）。保存后立即生效，无需重启。

分支节点命名（全局）

三个固定出口的显示名，作用于所有主题。留空 = 使用默认（验收 / 追问 / 其他）。命名只影响界面展示，不改变模型内部的提问逻辑。保存后立即生效，无需重启。

画布布局（全局）

作用于所有主题的知识树排版，单位 px，保存后刷新学习空间即可看到新的布局。注意：修改任一数值会重置所有节点的手动摆放位置，整棵树按新参数重新排版。默认：问答间距 24 / 分支衔接 82，卡片 300 × 180。

拆解模块（全局）

每个回答完成后附带的「镜片拆解」模块，默认全开。不想要的部分可关掉——关闭后不再生成，界面自动隐藏，不影响其他模块。保存后立即生效，无需重启。

绑定邮箱

用于忘记密码时接收重置邮件。选填，留空表示不绑定；需要验证当前密码。

修改密码

需验证当前密码。新密码 8-64 位，改完立即生效，其他登录会保持。修改成功后建议用新密码重新登录。
